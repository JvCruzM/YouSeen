# Política de Privacidade — YouSeen

**Última atualização:** 16 de setembro de 2026

O YouSeen é uma extensão de navegador focada em ocultar vídeos já assistidos nas páginas de canais do YouTube.

## Dados utilizados

Para executar sua única função, o YouSeen lê a informação de progresso de reprodução que o próprio YouTube exibe nas thumbnails dos vídeos.

A extensão não cria uma base própria de histórico de vídeos assistidos.

## Dados armazenados

O YouSeen armazena somente duas preferências da extensão usando `chrome.storage.sync`:

- ativação ou desativação da extensão;
- percentual escolhido para considerar um vídeo como assistido.

## Coleta e compartilhamento

O YouSeen não:

- envia dados de reprodução para um servidor próprio;
- vende ou compartilha dados do usuário com terceiros;
- utiliza serviços de análise, publicidade ou rastreamento;
- solicita login ou senha do YouTube;
- utiliza código remoto para executar a funcionalidade da extensão.

## Permissões

A extensão solicita acesso ao armazenamento do navegador para salvar as preferências e acesso às páginas do YouTube para aplicar a funcionalidade de ocultação nos canais.

Essas permissões são utilizadas exclusivamente para o propósito descrito nesta política e na página da extensão.

## Alterações

Esta política poderá ser atualizada caso o funcionamento do YouSeen seja alterado. A data de atualização será modificada quando houver uma nova versão relevante.
